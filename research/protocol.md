# Proposed evaluation protocol — not conducted

**Question.** Can selective approval reduce interruptions while preserving opportunities for human review of erroneous agent actions?

**Design.** Within-participant comparison of every-action approval and approval only for predefined sensitive actions. Counterbalance order and match task difficulty. All tasks and recipients are fictional.

**Outcomes.** Approval prompts, participant detection decisions against independently labelled error ground truth, false alarms, response time and subjective workload. Do not treat checker alerts as human detection.

**Implementation limitations.** This prototype contains fixed scenarios, a deterministic checker and an unvalidated interface. No recruited participants, randomization, ethics review or statistical outcomes are represented.

**Next steps.** Validate scenarios, implement event logging with participant consent, pre-register hypotheses and analysis, seek relevant institutional approvals, and run a feasibility pilot. Minimize and protect participant data.
